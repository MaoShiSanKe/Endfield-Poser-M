# Endfield Poser v0.4.5

本版包含 MMD 衣物惯性、固定跟随镜头和表情组合改进，并新增果冻回弹与角色自转彩蛋。

- MMD：衣物惯性增强、固定跟随镜头，以及多种表情组合支持。
- 彩蛋：活动模型伸缩回弹、本地音乐循环播放；角色自转可独立开启，支持正转、反转和每个模型固定随机方向。停止时恢复缩放与朝向。
- 排除 Canvas / RectTransform 界面及其子对象，保护角色目标，避免道具扫描接管角色父级。
- 本地接口修复：完整接收分段请求与较大的 JSON，请求异常时返回明确错误。

**果冻派对与角色自转为实验性功能，仅供娱乐，可能存在 bug。** 部分模型可能不跟随或与其他功能冲突；异常时请点击“停止并全部复原”，必要时重启游戏。工业模式中的射线塔、供电桩等设施不保证支持。本版不包含公转。

音乐由用户自行选择本地文件，安装包不包含歌曲。实验线摄像头与语音功能仍保持独立，不包含在本次正式版中。

安装：完全退出游戏，解压完整安装包，运行“安全安装.bat”；不要单独替换 DLL。配置、布局、姿态及自定义校准会保留。

验证：Windows x64 构建、HTTP / 回弹自转 / 镜头表情等本地回归检查通过；游戏内完成镜头、MMD 表情及彩蛋基本验收。衣物惯性和特殊场景的覆盖有限。
